> 项目：AI 跨境电商（选品分析 Agent + 商品内容生成 Agent）

## 1. 需求理解与业务边界

### 1.1 一句话理解

系统面向跨境电商运营场景，提供两条 Agent 流水线：

1. **选品分析 Agent**：从卖家精灵抓取商品 → 在 1688 匹配货源 → 利润测算与可配置规则筛选 → 侵权校验 → 展示商品池 → 两阶段人工核验 → 进入内容生成。
2. **商品内容生成 Agent**：基于候选商品生成商品内容 → 可编辑审核逻辑校验 → 人工审核 → 通过后上架亚马逊（暂定）。

### 1.2 业务边界

| 维度 | 边界 |
|---|---|
| 业务对象 | 商品（选品池商品、候选商品、生成内容、上架任务） |
| 外部数据源 | 卖家精灵（商品侧）、1688（货源侧）、亚马逊（上架目标，暂定） |
| 采集方式 | 无官方 API 条件下暂定爬虫**公开数据**；爬虫为**适配层**，非业务核心，须可开关、可降级（仅采公开可访问数据，不绕过登录/验证码） |
| 决策方式 | 规则引擎（利润/销售额/侵权）+ Agent 编排 + 两阶段人工核验 + 内容审核 + 人工终审 |
| 租户/组织 | 未明确是否多租户；本期按“单租户可扩展为多租户”设计，租户隔离字段预留（假设/待确认） |
| 账号/API | 当前无目标平台账号与 API；上架链路本期仅设计为“任务 + 人工确认/模拟上架”，真实上架待账号/API 确认 |

### 1.3 关键业务链路（端到端）

```
卖家精灵抓取 → 1688货源匹配 → 利润测算 → 筛选规则(单品毛利 OR 月销售额) → 侵权校验
  → 商品池(仅双维度未检出风险展示；不构成法律结论) → 人工初核 → 候选池 → 人工复核 → 内容生成Agent
  → 审核逻辑(运营可编辑) → 人工审核 → 上架亚马逊(暂定)
```

任一环节失败/不满足条件，商品进入**驳回/待处理/失败队列**，不进入下一环节；所有流转需可追溯（谁、何时、依据哪版规则）。

## 5. 核心状态机

### 5.1 商品池状态机（采集→展示）

```
COLLECTED → MATCHED → PROFIT_CALCULATED → INFRINGEMENT_CHECKED → IN_POOL
   │            │             │                      │
   └─失败队列───┴─无货源─────┴─规则不通过────────────┴─侵权/疑似 → REJECTED(拦截)
```

- `IN_POOL`：可展示、可初核。
- `REJECTED`：保留原因（规则/侵权/数据缺失），可人工复核或归档（策略待确认）。

### 5.2 候选池状态机（初核→复核）

```
IN_POOL → FIRST_REVIEW_PENDING → CANDIDATE → SECOND_REVIEW_PENDING → CONTENT_GEN_PENDING
              │驳回                    │驳回
              └→ REJECTED              └→ REJECTED(或回退商品池，待确认)
```

### 5.3 内容生成状态机（与详细设计 6.4 枚举一致）

```
PENDING → RUNNING → CONTENT_READY → AUDIT_PENDING → HUMAN_REVIEW_PENDING → APPROVED / REJECTED
   │          │失败/低置信
   │          └→ FAILED（转人工后可重跑）

```

- `content_jobs.status`：PENDING、RUNNING、CONTENT_READY、AUDIT_PENDING、HUMAN_REVIEW_PENDING、APPROVED、REJECTED、FAILED。
- 商品侧 `CONTENT_GEN_PENDING` 表示已复核待生成；内容任务侧 `PENDING` 表示已创建待运行。

### 5.4 人工审核状态机（内容审核）

```
AUDIT_PENDING → HUMAN_REVIEW_PENDING → APPROVED / REJECTED
（自动审核为 AUDIT_PENDING 内部步骤：执行审核逻辑 → 失败仍进 HUMAN_REVIEW_PENDING，BR-013 仍需人工终审）
```

### 5.5 上架状态机（与详细设计 6.4 枚举一致）

```
PENDING → RUNNING → LISTED / FAILED
（暂定：人工确认/模拟；方式未定 A-08）
```

- `listing_jobs.status`：PENDING、RUNNING、LISTED、FAILED。

> 详细状态定义、转换守卫、枚举值见《详细设计说明书》第 6 章与附录；本文件仅定义业务级状态。

## 6. 核心数据实体与数据流

### 6.1 核心实体（逻辑）

| 实体 | 说明 | 关键属性 |
|---|---|---|
| 商品（Product） | 统一商品主实体，贯穿池流转 | 平台、商品ID、标题、类目、价格、销量、状态机状态 |
| 货源（SupplierOffer） | 1688 匹配货源 | 供应商、成本、MOQ、匹配置信度 |
| 利润测算（ProfitCalculation） | 每次测算快照 | 输入、利润公式版本、汇率快照、规则版本、结果 |
| 侵权校验（InfringementCheck） | 专利/商标双维度校验记录 | 专利结论、商标结论、综合结论、证据 |
| 筛选规则（SelectionRule） | 可配置规则 + 版本 | 利润公式、汇率配置、阈值、币种、组合逻辑、版本 |
| 核验任务（ReviewTask） | 两阶段人工核验 | 阶段、审核人、结论、意见、SLA |
| 内容任务（ContentJob） | 内容生成任务 | Prompt版本、模型、Token、状态 |
| 生成内容（ContentArtifact） | 生成结果 | 标题/描述/卖点、置信度 |
| 审核逻辑（AuditRule） | 运营可编辑审核逻辑 + 版本 | 检查项、阈值、版本 |
| 审核记录（AuditRun） | 自动审核执行 | 检查项结果、结论 |
| 上架任务（ListingJob） | 上架执行 | 目标平台、状态、回执 |
| 采集任务（CrawlTask） | 爬虫任务 | 平台、适配器、状态、失败原因 |
| Agent 运行（AgentRun） | Agent 编排追踪 | 步骤、工具调用、成本 |

### 6.2 数据流

```
[卖家精灵页面] --爬虫适配器--> [原始数据区] --质量校验--> [商品主表]
[1688页面]     --爬虫适配器--> [货源表] ----匹配----> [商品主表]
[商品主表] --> [利润测算(规则版本)] --> [侵权校验] --> [商品池]
[商品池] --> [初核] --> [候选池] --> [复核] --> [内容生成Agent]
[内容] --> [审核逻辑(版本)] --> [人工审核] --> [上架任务] --> [亚马逊(暂定)]
```
