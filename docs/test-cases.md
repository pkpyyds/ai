## 4. 业务场景树

```
选品
├─ 正常流：抓取公开数据→匹配→测算通过（可配置公式/汇率）→专利+商标通过→商品池→初核→候选池→复核→内容生成
├─ 异常流：采集失败/字段缺失/反爬/无货源/规则不通过/侵权/核验驳回
└─ 边界流：阈值临界、空值、重复提交、并发、限流降级
内容
├─ 正常流：生成→自动审核通过→人工审核通过→上架任务
├─ 异常流：模型超时/工具失败/低置信/自动审核失败/人工驳回
└─ 边界流：审核逻辑版本回滚、Prompt注入、Token超限
通用
├─ 越权/租户隔离/幂等/审计/成本
└─ 采集合规开关/失败队列
```
